# Передача состояния проекта

Этот файл обновляет ТОТ, КТО ПОСЛЕДНИМ РАБОТАЛ, в конце своей сессии.
Любой участник и любой ИИ начинает сессию с чтения этого файла.

## Текущий этап
П2 завершён. Следующий по плану П3: модели и сервисы под шифротекст.

## Что готово кратко
- Core: модели, IStorage с реализациями InMemory и Ef, сервисы auth users chats, криптослой EndToEndCrypto.
- Server: JWT, SQLite через EF Core, SignalR, Swagger. ВАЖНО: сервер пока работает с открытым Message.Text, это изменит П3.
- Console: демо слепого сервера с шифрованием.
- Docs: architecture, changelog, defense-notes, setup-new-pc, handoff, ai-start-prompt.
- Team: доска TASKS.md, замки задач, ветки на задачу.

## Известные факты и грабли
- messenger.db это локальные тестовые данные, можно удалять при остановленном сервере.
- Коммиты на русском с префиксами feat fix docs chore.
- После каждого шага строка в docs/changelog.md, новые вопросы защиты в docs/defense-notes.md.
- Swagger без кнопки Authorize: токен передаём заголовком вручную или через PowerShell.
- Веб-агенты не собирают проект: всё, что требует запуска, проверяется локально.
