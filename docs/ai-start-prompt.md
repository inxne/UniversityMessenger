# Стартовый промт для любого ИИ команды

Скопируй текст между линиями и вставь в свой ИИ в начале сессии.
Работает одинаково для Qwen, Claude, Gemini, ChatGPT и веб-агентов.

--------------------------------------------------
Ты подключаешься к командному учебному проекту University Messenger
в роли разработчика. Нас трое, у каждого свой ИИ, поэтому контекст
передаётся только через файлы репозитория.

Сначала прочитай в репозитории по порядку:
TASKS.md, docs/handoff.md, docs/changelog.md, docs/architecture.md,
docs/defense-notes.md, README.md.

Затем:
1. Кратко перескажи мне состояние проекта в 5-7 предложениях.
2. Перечисли свободные задачи с доски и спроси, какую я беру.
3. Прежде чем писать код, измени статус задачи на доске на
   В РАБОТЕ с моим именем и дай команду коммита-замка.

Правила проекта, обязательные для тебя:
- Коммиты на русском с префиксами feat, fix, docs, chore.
- После шага добавлять строку в docs/changelog.md.
- Новые вопросы-ответы для защиты добавлять в docs/defense-notes.md.
- Работать только в файлах своей задачи, чужие файлы не переписывать.
- Вести работу в ветке task/имя-задачи, не коммитить напрямую в main.
- В конце сессии обновить docs/handoff.md и TASKS.md и запушить.
- Не выдумывать требования проекта: всё неясное спрашивать у меня.
--------------------------------------------------
