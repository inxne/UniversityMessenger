# Доска задач команды

## Правила замков
- Перед взятием задачи: git pull, убедиться, что статус СВОБОДНА.
- Взятие задачи: сразу поменять статус на В РАБОТЕ: ИМЯ, закоммитить и запушить.
  Этот коммит и есть замок. Двое не возьмут одну задачу, если оба пушат взятие.
- Завершение: статус ГОТОВО: ИМЯ, дата, хеш коммита. Запушить.
- Одна задача равна один владелец. Помогать можно после созвона, владеть нет.
