# University Messenger

Корпоративный мессенджер с оконечным шифрованием (end-to-end encryption).
Предназначен для развёртывания на локальной инфраструктуре организации.

## Ключевые свойства

- **Оконечное шифрование**: сервер хранит только шифротексты, ключи существуют только на устройствах пользователей
- **On-premise размещение**: данные не покидают инфраструктуру организации, соответствует требованиям 152-ФЗ
- **Слепая модель**: при изъятии или компрометации сервера злоумышленник получает набор случайных байтов без возможности восстановления текстов
- **Обмен ключами ECDH**: каждый чат имеет свой общий секрет, выведенный из пары ключей участников
- **Шифрование AES-GCM**: аутентифицированное шифрование с проверкой целостности

## Стек

- C#, .NET 10
- ASP.NET Core (сервер, минимальные API)
- JWT-токены через Microsoft.AspNetCore.Authentication.JwtBearer
- EF Core + SQLite (хранение данных на локальном сервере)
- System.Security.Cryptography (ECDH + AES-GCM для оконечного шифрования)
- SignalR (реалтайм-доставка шифротекстов)
- .NET MAUI (клиент, в разработке)

## Структура

- src/UniversityMessenger.Core — ядро: модели, хранилище, сервисы, криптография

## Модель угрозы

**Что защищено:**
- Содержание всех сообщений (шифротексты нечитаемы без приватных ключей)
- Приватные ключи существуют только на устройствах пользователей
- Сервер не имеет технической возможности прочитать переписку

**Что не скрыто (честное ограничение E2E):**
- Метаданные: кто с кем переписывается и когда
- Объём трафика между пользователями
- Публичные ключи (они публичные по определению)

Для защиты метаданных требуются дополнительные механизмы (например, сети типа Tor), что выходит за рамки корпоративного on-premise решения.

## Возможности

- Регистрация с проверками и согласием на обработку персональных данных
- Вход по почте и паролю, пароль хранится только в виде хеша
- Вход выдаёт JWT-токен, закрытые эндпоинты знают пользователя по токену
- Поиск пользователей по ФИО без учёта регистра, фильтры по роли, факультету, курсу
- Личные чаты с оконечным шифрованием (один чат на пару через DirectKey)
- Групповые чаты с обернутым ключом для каждого участника
- Отправка зашифрованных сообщений с проверкой участия в чате
- История переписки в зашифрованном виде
- Реалтайм-доставка шифротекстов через SignalR
- Данные хранятся в SQLite на локальном сервере и переживают перезапуск

## Запуск демо ядра

    dotnet run --project src/UniversityMessenger.Console

## Запуск сервера

    dotnet run --project src/UniversityMessenger.Server

Затем открыть http://localhost:5000/swagger
